# EdTech UI/UX Design Standard

Design and implement this website as a **serious, modern human-designed EdTech product**, not as an AI-generated demo.

## Core aesthetic

* Clean, restrained, editorial, professional and human.
* Prioritize clarity, hierarchy, typography, spacing and usability over decoration.
* Make the interface feel designed by an experienced product designer.
* Use a consistent visual system across every page.
* Prefer subtle visual details over obvious effects.

## Strictly avoid

* AI-looking or "vibe-coded" interfaces.
* Cartoonish illustrations, mascots, robots, floating 3D objects or generic AI imagery.
* Excessive gradients, glassmorphism, glowing effects, neon colors or excessive rounded cards.
* Random icons, decorative blobs, oversized emoji, unnecessary animations or visual noise.
* Generic SaaS/dashboard templates.
* Excessive cards where a simple layout would communicate better.
* Huge headings surrounded by empty space merely to look impressive.
* "AI startup" visual clichés.

## UI principles

* Use strong typography and whitespace to establish hierarchy.
* Keep navigation simple and predictable.
* Use a restrained color palette with one clear accent color.
* Use borders, dividers and subtle elevation sparingly.
* Use consistent spacing, radius, iconography and component behavior.
* Prefer real content and meaningful interface elements over decorative filler.
* Every visual element must have a functional or communicative purpose.
* Design mobile-first and ensure excellent desktop layouts.
* Accessibility, readability and interaction clarity take priority over visual novelty.

## EdTech character

The product should feel like a **trusted university-quality learning platform**: calm, intelligent, credible, approachable and focused on learning.

Think **modern academic product + excellent editorial design**, not an AI startup landing page.

## Before implementing UI

First inspect the existing application, design system, components and pages. Reuse and improve existing patterns instead of creating new visual styles unnecessarily.

When redesigning a page, preserve its functionality and information architecture unless there is a clear UX reason to improve them.

## Quality gate

Before considering a UI task complete, review the result visually and ask:

1. Does this look human-designed rather than AI-generated?
2. Is anything decorative that does not improve usability?
3. Is the hierarchy immediately understandable?
4. Does the typography feel intentional?
5. Is the spacing balanced?
6. Are colors restrained and purposeful?
7. Does it look credible enough for a serious educational institution?
8. Does it remain excellent on mobile?
9. Does every component feel like part of the same product?

If the answer to any of these is no, refine the design before finishing.
